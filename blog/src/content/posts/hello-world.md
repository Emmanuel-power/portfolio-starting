Every developer I admire has one habit in common: they write things down. So this is
where I'll do the same.

## Why a blog?

- **To learn faster.** Explaining something forces me to actually understand it.
- **To remember.** Future me will forget how I fixed that build error. This blog won't.
- **To show my work.** A record of real progress beats a list of buzzwords on a resume.

## What I'll write about

I'll post about what I'm learning, the projects I'm building, and the mistakes I make
along the way. Some posts will be polished; many will be short notes.

## How this post was made

Each post is a Markdown file in `src/content/posts/`. Code blocks get syntax highlighting:

```ts
const journey: string[] = [];
journey.push('Day 1: started a blog');
console.log(`${journey.length} entry so far`);
```
